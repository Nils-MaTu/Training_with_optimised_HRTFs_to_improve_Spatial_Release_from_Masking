\section*{Highlights}

\begin{itemize}
  \item Optimised HRTFs increased spatial release from masking.
  \item Optimised HRTFs did not impair front--back discrimination.
  \item Brief training improved discrimination with the optimised HRTF.
  \item Training added little SRM benefit beyond HRTF optimisation.
\end{itemize}
